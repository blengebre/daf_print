# D.A.F Printing Plc (ዲ.ኤ.ኤፍ ማተሚያ ቤት)

Official web application for **D.A.F Printing Plc** — a premier custom merchandise and printing house based in Addis Ababa, Ethiopia.

---

## 🌟 Key Features

- **Personalized Product Customizer**:
  - Live interactive mockup on T-shirts, ceramic mugs, official stamps, and stickers.
  - Custom typography engine supporting **Ge'ez / Amharic** (`Noto Sans Ethiopic`) and Latin display fonts.
  - Image upload from device, search from curated Ethiopian graphics library, or paste direct image URLs.
  - Rotate, scale, flip, and background removal tools.
  - **Smart AI Auto-Proportion Engine**: Automatically calculates safe print bounds (300 DPI), auto-centers artwork, and balances contrast.

- **Dual Language Support (English & አማርኛ)**:
  - 1-click instant language toggle between English and authentic Amharic across the entire application.

- **Ethiopian Payment Integration**:
  - **Telebirr**: Direct phone & merchant till transfer (`0930077432`).
  - **Commercial Bank of Ethiopia (CBE)**: Direct account transfer (`1000 2489 31924`).
  - SMS transaction reference verification.
  - Guaranteed arrival countdown and printable official digital receipt.

- **Delivery Urgency Surcharges & Scheduling**:
  - Standard Production (Free, 3-5 days).
  - Priority Fast-Track (+15% surcharge, 48 hours).
  - Same-Day / Super Urgent (+30% surcharge, within 24 hours).
  - Calendar arrival date picker.

- **Dedicated Order Receiver Workshop Terminal**:
  - Live order management for print operators.
  - Visual preview of designs rendered directly on product mockups.
  - Pre-press visual editor to fine-tune text, scale, colors, and artwork before sending to press.

---

## 🛠️ Tech Stack

- **Frontend**: React 19, Vite 8, Tailwind CSS v4
- **Icons**: Lucide React
- **Animations**: Canvas Confetti, Tailwind CSS animations
- **Internationalization**: Custom lightweight i18n engine

---

## 🚀 Getting Started

### 1. Install Dependencies
```bash
npm install
```

### 2. Run Locally in Development
```bash
npm run dev
```
Open [http://localhost:5173](http://localhost:5173) in your browser.

### 3. Build for Production
```bash
npm run build
```
